# VOID/FORM — vibe code studio

A development studio website that exists in the space between code and consciousness.

## Concept

This is not a website. It's a **void** — a living, breathing digital space where:
- Text materializes from particles
- 3D orbs float and respond to touch
- The background is a custom WebGL fluid simulation
- Navigation happens through pulse, not scroll
- Every section is a "manifestation" in the void

## Tech Stack

- **Vite** — Build tool
- **Three.js** — 3D graphics and WebGL
- **GSAP** — Animation
- **Custom GLSL shaders** — Fluid void background, particle systems
- **Vanilla JS** — No framework, just vibes

## Features

### Visual Language
- Deep black void with bioluminescent phosphor accents
- Custom grain and scanline overlays
- Glitch typography with RGB split
- Asymmetric, organic layouts
- No cards, no borders, no boxes

### Interactions
- **Custom cursor** — A light source that changes contextually
- **WebGL fluid background** — Responds to mouse with flowing noise
- **Particle text** — Text forms from and dissolves into particles
- **3D orb field** — Draggable project orbs with physics
- **Heartbeat system** — Everything pulses to a rhythm
- **Portal transitions** — Sections connect through void portals

### Sections
1. **Entry** — A single point of light. Click to enter.
2. **Manifesto** — Philosophy as floating text
3. **Process** — The flow state visualized as a river
4. **Work** — Projects as draggable 3D orbs
5. **Contact** — A portal to another dimension

### Easter Eggs
- Konami code: ↑↑↓↓←→←→BA activates rainbow mode
- Hidden cursor labels
- Time display shows both real time and session time
